# nori

Clickable class prototype for **nori** — a social nutrition and accountability app for small friend squads.

Friends set personal protein goals, log meals, and contribute to a shared weekly quest. Consistency (not total macros) drives squad rank and a sample end-of-season gift-card reward.

## Run locally

```bash
npm install
npm run dev
```

Open [http://127.0.0.1:43123](http://127.0.0.1:43123).

## Demo flow

1. Join the preset squad **Protein Pod**
2. Tap **Log lunch**, keep Share to squad quest on, save
3. Watch weekly goal-days move to **15/20** and the quest to **9/12**
4. Open **Rank** for the projected gift-card amount
5. Open **Weekly recap** to see why coming back next week matters

## What’s simulated

Fake meal data, a preset squad, fixed rank levels, and sample reward amounts. No real nutrition API, accounts, payments, or live leaderboard.

## Stack

Next.js, TypeScript, Tailwind CSS.
